# 界面截图指南

README 顶部的预览图与「界面预览」表格引用了 `docs/images/` 下的文件。目前这些图取自本应用
的真实界面（上游时期的英文截图，已裁掉宣传语）。想换成**中文界面 / 自己设备**的截图，按下表
截 6 张覆盖同名文件即可，无需改 README。

## 需要哪几张

| 文件名 | 拍哪个界面 | 建议内容 |
|---|---|---|
| `preview-receive.jpg` | 底部导航 **接收** 页 | 显示设备别名 + 接收/发送/设置 |
| `preview-send.jpg` | **发送** 页 | 已选内容（文件/媒体/文本/文件夹）+「附近设备」列表里有另一台设备 |
| `preview-confirm.jpg` | 接收方的**确认弹窗** | 显示「XXX 想发送 N 个文件」+ 拒绝/接受 |
| `preview-progress.jpg` | **传输中**页面 | 文件列表 + 总进度 + 详情/取消 |
| `preview-dark.jpg` | **深色模式**下的发送页 | 设置里切换主题后截图 |
| `preview-crossplatform.jpg` | **手机 ↔ 电脑互传** | 一侧手机、一侧桌面端（横图更好） |

`preview-strip.jpg` 是顶部的四联预览图（由前 4 张并排合成），换了前 4 张后重新合成一次即可
（见下方命令）。

## 怎么截

**Android**：电源键 + 音量减；或 `adb exec-out screencap -p > shot.png`。
**macOS**：`⇧⌘4` 区域截图（推荐只截应用窗口，先按空格可整窗截图）。
**Windows**：`Win + Shift + S`。
**iOS**：侧边键 + 音量加。

建议：竖图 1080×1920 或同比例；横图 2560×1440。图片宽度超过 1000px 时在 README 里会被缩小显示。

## 放在哪 / 怎么处理

把截图拷到仓库的 `docs/images/` 目录，命名为上表的名字（jpg 或 png 都行，注意与 README 中的
引用一致，或同步修改 README 里的文件名）。

若截图带了边框外的空白或顶部宣传语，可用下面的脚本按比例裁切并压缩（需要 Pillow）：

```bash
# 竖图：裁掉顶部 23%，仅保留设备界面；宽度压到 540
python3 - <<'PY'
from PIL import Image
im = Image.open("raw-receive.jpg").convert("RGB")
w, h = im.size
im = im.crop((0, int(h*0.23), w, h))
im = im.resize((540, int(540*im.height/im.width)))
im.save("docs/images/preview-receive.jpg", quality=88, optimize=True)
PY
```

重新合成顶部四联预览图：

```bash
python3 - <<'PY'
from PIL import Image
names = ["preview-receive", "preview-send", "preview-confirm", "preview-progress"]
imgs = [Image.open(f"docs/images/{n}.jpg") for n in names]
gap, h = 10, max(i.height for i in imgs)
strip = Image.new("RGB", (sum(i.width for i in imgs) + gap*3, h), "#0d5f59")
x = 0
for i in imgs:
    strip.paste(i, (x, 0)); x += i.width + gap
strip.save("docs/images/preview-strip.jpg", quality=85, optimize=True)
PY
```

## 截图里的注意事项

- 别暴露真实姓名、手机号、私密文件名；设备别名可以在设置里改成示例名（如 `Determined Lemon`）；
- 传输中的截图尽量选示例文件（如 `demo-video.mp4`）；
- 三张接收相关截图建议用同一台设备，观感统一。
